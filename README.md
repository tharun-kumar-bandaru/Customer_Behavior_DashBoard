🔍 Project Overview

This project analyzes customer purchasing behavior using SQL, Python, and Power BI.
The interactive dashboard provides insights into:

Customer demographics
Subscription behavior
Revenue & sales trends
Age-group based purchasing patterns
Category-wise performance
The goal is to enable data-driven business decisions through clean data modeling and visualization.

📌 Data Processing

📌 Database

Power BI Desktop
DAX Measures
Interactive Filters & Slicers

Git & GitHub

🧾 Dataset Description
Column Name	          Description
Customer_ID	          Unique customer identifier
Gender	              Male / Female
Age_Group	            Young Adult / Adult / Middle-aged / Senior
Category	            Clothing, Accessories, Footwear, Outerwear
Purchase_Amount	      Amount spent per transaction
Review_Rating	        Customer rating (1–5)
Subscription_Status	  Yes / No
Shipping_Type	        Standard, Express, Same Day, etc.

Python – Data Cleaning & Analysis

🎯 Business Insights Generated

Clothing category generates highest revenue
Middle-aged customers contribute most to revenue
Subscription adoption is low (≈14%)
Adults have higher purchase frequency
Standard shipping is most preferred
